
目标：“以MFEM为数值计算内核、以智能体为流程组织者、以独立验证器为质量闸门”的科学工程计算系统，先期支持软件中的各个算例的自主高性能计算。



MFEM适合承担有限元空间、离散算子、网格自适应、线性与非线性求解及并行计算等核心工作，但它本身不覆盖完整的CAD建模、需求理解、计算资源调度、结果审查和科研知识管理。因此，需要在MFEM外部增加统一问题描述、工具服务、智能体编排和验证追溯四个层次。

## 一、总体架构

```
自然语言需求、数学模型、工程文件和实验数据
                    │
          总控智能体与统一问题描述
                    │
     ┌──────────────┼──────────────┐
     │              │              │
 建模智能体     数值方法智能体    计算执行智能体
     │              │              │
方程、几何、     网格、空间、      环境、资源、
材料、初边值     离散、求解器      并行与监控
     └──────────────┼──────────────┘
                    │
              MFEM求解服务
                    │
     ┌──────────────┼──────────────┐
     │              │              │
验证复核智能体  可视化智能体   证据与知识管理
     │              │              │
误差、守恒、     场分布、派生量、  配置、代码、日志、
收敛、基准       比较和报告        失败案例与版本
                    │
        接受结果、重新计算或人工审批
```

MFEM的优势在于将网格、有限元空间、算子和线性代数相对清晰地分离，并支持高阶H¹、L²、H(curl)、H(div)和NURBS空间、并行自适应、部分装配以及GPU加速，适合作为可组合的数值求解底座。[MFEM功能说明](https://mfem.org/features/)

## 二、需要建立的核心智能体

### 1. 数理建模智能体

职责是把自然语言问题转化为可计算的问题定义，而不是直接生成一段未经检查的MFEM代码。

需要表达：

- 控制方程及其强形式、弱形式；
- 稳态、瞬态、特征值或参数反演问题；
- 标量场、向量场及多物理场之间的耦合关系；
- 材料参数、源项和本构关系；
- 初始条件、边界条件和界面条件；
- 关注量，如阻力、热流、反应率、特征频率；
- 精度、守恒、稳定性和计算时间要求。

可配套的工具包括符号计算、量纲检查、弱形式推导、自动微分和方程知识库。

其输出应是结构化的`ProblemSpec`，而不只是文字说明。

### 2. 几何与网格智能体

MFEM能够读取和处理多种网格，支持曲边高阶网格、局部加密、非协调加密、TMOP网格优化以及与PUMI等工具集成，但复杂CAD区域通常仍需要外部几何与网格工具。[MFEM网格能力](https://mfem.org/features/)

建议工具：

- CAD处理：OpenCASCADE、STEP/IGES接口；
- 网格生成：Gmsh、Cubit等；
- 分布式网格：PUMI；
- MFEM内部处理：`Mesh`、`ParMesh`、曲边化、加密、解加密、负载均衡和TMOP；
- 网格质量检查：Jacobian、长宽比、扭曲度、高阶单元有效性；
- 区域标记：材料区域、边界属性和界面属性。

智能体需要完成：

1. 识别几何尺度、薄层、尖角和小孔；
2. 判断是否简化几何；
3. 选择三角形、四边形、四面体、六面体或混合网格；
4. 确定几何阶次与有限元阶次；
5. 检查区域和边界标记；
6. 根据误差估计进行局部加密或网格优化。

MFEM示例已经覆盖曲边高阶网格、局部自适应以及Gmsh命名区域和边界的使用，可作为工具模板库。[MFEM示例与小型应用](https://mfem.org/examples/)

### 3. 初边值条件智能体

该智能体负责把物理描述映射到MFEM中的系数、边界属性和约束处理。

需要处理：

- Dirichlet、Neumann、Robin及混合边界条件；
- 周期边界、对称边界、滑移边界和吸收边界；
- H(curl)切向边界与H(div)法向边界；
- 随时间或参数变化的初边值条件；
- 材料界面上的连续性、跃迁和通量条件；
- 初值与边界条件的相容性。

关键工具包括：

- MFEM的`Coefficient`、`VectorCoefficient`；
- 边界属性集合；
- essential true dof提取；
- 投影与插值工具；
- 边界条件相容性检查器。

这一环节应自动生成“边界属性—物理名称—数学条件—MFEM实现”的映射表，供用户确认。

### 4. 离散方法智能体

它根据方程结构选择有限元空间、弱形式和装配方式。

典型选择包括：

| 问题结构               | 建议空间或方法            |
| ---------------------- | ------------------------- |
| 扩散、热传导、结构位移 | H¹协调有限元              |
| 输运、守恒律、间断解   | DG或L²空间                |
| Maxwell、电磁场        | Nédélec H(curl)空间       |
| Darcy、守恒通量        | Raviart–Thomas H(div)空间 |
| 不可压流、多场耦合     | 混合有限元或块系统        |
| 高阶复杂几何           | 等参高阶有限元或NURBS     |
| 局部误差显著           | h、p或hp自适应            |

智能体还要选择：

- Galerkin、DG、DPG或混合方法；
- 单元积分阶次；
- 质量矩阵是否集块；
- 全装配、部分装配或无矩阵计算；
- 静态凝聚、杂交化；
- 显式、隐式或IMEX时间推进；
- 稳定化、限幅和人工黏性；
- 后验误差估计与自适应策略。

MFEM提供混合有限元、DG、DPG、静态凝聚、杂交化和部分装配等能力，可以把现有示例与miniapp封装为“离散策略模板”。[MFEM离散能力](https://mfem.org/features/)

### 5. 求解器与预条件子智能体

这一部分不能只根据矩阵规模选择算法，而要识别离散系统的数学结构。

首先提取问题特征：

- 对称或非对称；
- 正定、不定或鞍点；
- 线性或非线性；
- 刚性或非刚性；
- 单场或块耦合；
- 条件数、各向异性和系数跳跃；
- H¹、H(curl)、H(div)或混合空间。

然后生成候选方案：

- SPD系统：CG与AMG；
- 非对称系统：GMRES、FGMRES与ILU/AMG；
- 鞍点系统：MINRES、GMRES与块预条件；
- 非线性系统：Newton–Krylov、阻尼Newton、Picard；
- H(curl)/H(div)：辅助空间或多层次预条件；
- 高阶无矩阵系统：低阶精化预条件、多重网格；
- 强耦合系统：物理分裂、Schur补或场分裂；
- 瞬态刚性问题：隐式或IMEX时间积分。

可调用的工具包括MFEM内置Krylov和Newton求解器，以及HYPRE、PETSc、SUNDIALS、SuperLU、STRUMPACK、libCEED、Ginkgo等外部库。MFEM官方示例已经展示了BoomerAMG、LOBPCG、并行直接求解器、PETSc和SUNDIALS等组合。[MFEM求解器教程](https://mfem.org/tutorial/solvers/) [MFEM示例](https://mfem.org/examples/)

智能体选择求解器时应输出理由、适用条件、备选方案和回退条件，而不是只输出一个名称。

### 6. 计算环境适配智能体

主要负责把抽象计算方案映射到实际硬件和软件环境。

需要管理：

- MFEM版本、编译器和依赖版本；
- MPI进程数和线程数；
- CPU、GPU或异构后端；
- CUDA、HIP、RAJA、OCCA、OpenMP等执行方式；
- HYPRE、METIS、PETSc等依赖；
- CMake、Spack或容器环境；
- Slurm等作业调度系统；
- 内存、显存、通信网络和文件系统约束。

智能体应先进行环境探测，再决定：

- 串行或并行版本；
- 全装配或部分装配；
- MPI进程与设备绑定；
- 网格分区方案；
- 检查点频率；
- 结果输出频率；
- 资源申请规模。

MFEM支持MPI并行和CUDA、HIP、OCCA、RAJA及OpenMP等设备后端，适合建立统一的后端配置模板。[MFEM GitHub说明](https://github.com/mfem/mfem)

### 7. 工况与参数智能体

负责管理单次计算之外的参数空间探索：

- 材料参数、载荷、边界条件和几何参数；
- 初始工况、极端工况和失效工况；
- 网格阶次、时间步长和求解容差；
- 参数扫描、敏感性分析和不确定度量化；
- 设计优化、数据同化和参数反演；
- 多保真计算与代理模型。

它需要区分：

- 物理参数；
- 数值参数；
- 性能参数；
- 不允许自动修改的安全参数。

参数选择可以采用规则、试验设计、贝叶斯优化或主动学习，但每次修改都要保留来源和理由。

### 8. 并行执行与监控智能体

职责包括：

1. 生成MFEM配置和运行命令；
2. 提交批处理作业；
3. 监控残差、迭代次数、时间步和资源使用；
4. 识别发散、停滞、NaN、内存不足和通信异常；
5. 自动调整容差、时间步或资源；
6. 从检查点恢复；
7. 保存运行日志和性能剖析结果。

应同时监测两类信号：

- 数值信号：残差、守恒偏差、能量变化、关键物理量；
- 硬件信号：计算利用率、显存占用、带宽、通信和I/O时间。

智能体可以提出调整建议，但不得在没有复核的情况下静默改变物理模型、离散格式或验收标准。

### 9. 验证与复核智能体

这是整个系统最重要的可信性保障。需要把“程序运行成功”和“结果正确”严格分开。

建议设置多级验证闸门：

#### 第一级：输入验证

- 单位和量纲一致；
- 几何及网格有效；
- 材料和边界条件完整；
- 初边值条件相容；
- 参数位于合理范围。

#### 第二级：离散验证

- 制造解测试；
- 精确解误差；
- 网格收敛和阶次收敛；
- 时间步收敛；
- 守恒、保正和能量稳定检查。

#### 第三级：求解验证

- 线性和非线性残差；
- 迭代收敛历史；
- 约束违反程度；
- 预条件器鲁棒性；
- 不同求解器交叉比较。

#### 第四级：物理复核

- 质量、动量和能量平衡；
- 对称性和极限行为；
- 关键物理量范围；
- 与实验、文献或基准算例比较；
- 与另一套独立代码交叉验证。

#### 第五级：不确定度与适用范围

- 参数不确定度；
- 网格和模型不确定度；
- 分布外工况识别；
- 结论对参数扰动的敏感程度。

MFEM自带示例包含精确解误差计算、自适应误差估计和不同有限元空间的验证方法，可以作为自动验证模板的起点。[MFEM示例](https://mfem.org/examples/)

### 10. 可视化与报告智能体

建议分为快速查看和正式分析两层：

- GLVis：快速查看MFEM高阶网格和有限元场；
- ParaView、VisIt：大规模并行后处理；
- Python分析工具：曲线、误差、收敛率和参数比较；
- 自动报告：模型、网格、离散、求解器、资源、误差和结论。

MFEM原生支持GLVis，并可向ParaView和VisIt输出高阶结果。[MFEM可视化能力](https://mfem.org/features/)

智能体还应自动生成：

- 网格质量图；
- 场变量云图；
- 残差与收敛曲线；
- 守恒误差曲线；
- 参数敏感性图；
- 不同工况对比图；
- 计算成本和并行效率图。

## 四、推荐的完整工作流程

### 步骤1：需求受理

用户提交问题描述、几何文件、材料数据、实验数据和目标精度。智能体通过问答补齐缺失信息，并区分“已知事实、用户假设和待确定参数”。

### 步骤2：形成计算问题说明书

建模智能体输出方程、未知量、初边值条件、关注量和验收标准。用户确认后才进入后续计算。

### 步骤3：几何清理与区域标记

读取CAD或已有网格，消除小特征和几何缺陷，标记材料区域、边界和界面，生成可追溯的几何版本。

### 步骤4：网格方案生成与检查

生成多个候选网格，评价质量、规模和高阶曲边有效性。必要时使用TMOP优化，并为局部加密保留规则。

### 步骤5：生成弱形式与离散方案

选择有限元空间、阶次、积分规则、稳定化和装配方式，生成MFEM算子配置及候选代码。

### 步骤6：求解器与预条件子协同选择

根据算子性质生成若干求解方案，在缩小算例上进行预试验，比较迭代次数、内存、时间和鲁棒性，再确定正式方案。

### 步骤7：计算环境适配

探测目标平台，完成MFEM及依赖配置、设备后端选择、进程绑定、分区和资源估算。

### 步骤8：小规模预检

在粗网格和缩短时间区间上运行，检查：

- 方程及边界条件是否正确；
- 解是否具有合理量级；
- 残差是否收敛；
- 是否满足基本守恒；
- 输出和检查点是否可用。

### 步骤9：正式并行执行

提交正式作业，持续监控数值状态和硬件状态。发生异常时，优先采用检查点恢复、局部重试或切换备选求解器。

### 步骤10：验证与高保真复核

执行网格收敛、时间步收敛、守恒检查和基准比较。未通过验证的结果不得进入最终报告；智能体应回退到网格、离散或求解配置重新计算。

### 步骤11：可视化和科学解释

生成场分布、关键派生量、参数比较和误差图。智能体可以帮助归纳现象，但科学结论必须能追溯到计算数据和验证证据。

### 步骤12：沉淀可复用工作流

把问题定义、网格规则、MFEM代码、求解配置、运行环境、验证脚本和结果模板保存为一个版本化工作流。

## 五、智能体的决策闭环

建议采用以下状态机，而不是让大模型自由调用工具：

```
需求理解
  ↓
问题形式化
  ↓
候选计算方案
  ↓
规则与静态检查
  ↓
小规模试算
  ↓
独立验证
  ├─ 通过：扩大规模或进入正式计算
  ├─ 不通过：返回网格、离散或求解器环节
  └─ 风险较高：提交人工确认
  ↓
正式计算
  ↓
验证复核
  ↓
结果发布与知识沉淀
```

其中，大模型负责理解、规划、解释和候选方案生成；确定性程序负责网格检查、代码编译、数值计算和误差验证；独立验证器负责决定接受、回退或人工审批。

## 七、开发实施建议

### 第一阶段：单类方程的最小闭环

先选择Poisson、热传导或线弹性问题，实现：

> 问题描述—网格—MFEM代码—求解—误差检查—GLVis/ParaView输出

这一阶段重点不是追求智能程度，而是打通统一数据结构和确定性工具链。

### 第二阶段：多种离散与求解策略

增加H(curl)、H(div)、DG、非线性问题和瞬态问题，建立离散方法、求解器和预条件器的规则库。

### 第三阶段：并行与国产环境适配

接入MPI、GPU和作业调度系统，实现资源估算、自动提交、运行监控、检查点恢复和性能测量。

### 第四阶段：长程闭环和多智能体协同

增加参数扫描、反演、优化、自适应加密及高保真复核，使智能体能够根据验证结果返回前序环节。

### 第五阶段：应用示范

选择一个边界清晰、已有基准的真实问题，完成：

- 复杂几何；
- 多工况计算；
- 目标规模并行；
- 独立验证；
- 人在回路；
- 全过程追溯。

## 八、最关键的设计原则

1. **MFEM是求解内核，不是整个智能体系统。**几何、调度、验证和知识管理需要外围工具支撑。
2. **统一问题描述比对话界面更重要。**如果方程、边界、网格和验收条件没有结构化，自动化很难可靠。
3. **智能体负责提出方案，验证器负责决定是否接受。**不能让生成方案的智能体同时充当最终裁判。
4. **先建立规则和模板，再引入学习型决策。**求解器和预条件器选择初期应以算子结构和经过验证的规则为主。
5. **每次运行都必须可复现。**模型、网格、代码、参数、环境、日志和验证结果必须形成完整证据链。
6. **高成本和高风险操作需要人在回路。**改变物理模型、放宽误差标准、执行大规模计算或发布工程结论时，应要求人工确认。

这个系统最终交付的不是一个“会生成MFEM代码的聊天机器人”，而是一套能够理解问题、组合可信工具、执行高性能计算、发现失败并返回修正、完成独立验证和保存全部证据的科学工程计算智能体工作流。
