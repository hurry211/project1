# CFAC 稀疏证书与原空间下限筛查

## 适用范围

本阶段保持原 CFAC checker 的二维单位正方形、相容三角网格、齐次 Dirichlet、正常数扩散和原始分片常数载荷合同。采用 P1 原场，以及 RT0 或 RT1 平衡通量。已有投影载荷、平衡缺陷和振荡项仍由既有 checker 处理。下面的分解只用于原始 P0 数据和零平衡缺陷。

## 定原场的 RT1 互补能量优化

设 $v$ 为给定的 P1 场，$q_0$ 是任一精确平衡的 RT0 或 RT1 通量。固定网格、载荷与扩散系数 $a$ 后，同空间的可行 RT1 通量可写成 $q=q_0+\operatorname{curl}\psi_h$。这里 $\psi_h$ 为连续 P2 势函数，钉住一个顶点去掉常数核。零散度的 RT1 校正逐元仿射，法向连续等价于势函数的切向导数跨面一致。区域单连通给出全局连续势。Dirichlet 边界不约束法向通量。

由于 $(\nabla v,\operatorname{curl}\psi_h)=0$，最小化间隙 $\|a^{-1/2}(q-a\nabla v)\|^2$ 等价于最小化 $\|a^{-1/2}q\|^2$。因此无需重求 P1 原问题。三点边中点公式对仿射通量、P2 势梯度的二次乘积精确。实现按 P1 顶点帽与 P2 边泡函数分块组装 CSR，以钉住后的 P1 块稀疏因子和边泡函数的 Jacobi 对角项作为块预条件器。另设纯 Jacobi、局部 RT1 patch 初值及不同检查频率的消融。

设全局定向边从 $i$ 到 $j$，$s_i,s_j$ 为端点势值，$b_e$ 为边泡函数系数。将浮点候选当成精确二进制有理数后，两阶法向矩增量分别为 $s_j-s_i$ 和 $(s_j-s_i)/2-2b_e/3$。单元向量矩增量为面积乘重心处的旋转梯度。这样写出 RT1 矩，可在精确算术中保持原有法向连续与散度，无需用浮点残差充当平衡证据。最终由原 RT1 checker 重新构造多项式、按冻结载荷积分并独立验收。

在精确 PCG 算术中，流函数坐标修正 $x$ 的目标下降为 $2b^Tx-x^TAx=x^T(b+r)$，其中 $r=b-Ax$。实现把浮点下降量只用于安排下一次检查。变体比较每次迭代检查、迭代数为二的幂时检查，以及结合预计越过目标阈值的检查。到预算边界必须独立检查候选。实际下降量、估计下降量及真实 PDE 误差是不同量。

## 稀疏代数误差区间

令 $R=r^TK^{-1}r$ 为离散代数误差能量。对任意试验校正 $z$，有恒等式

$$R=2r^Tz-z^TKz+(r-Kz)^TK^{-1}(r-Kz).$$

浮点稀疏 PCG 只产生 $z$。程序对二进制有理数 $z$ 精确求 $Kz$ 与试验下降，后者是严格下界。对剩余载荷 $s=r-Kz$ 用质量矩阵和 Poincaré 界。设 $m_i$ 是 P1 集中质量，逐元一致质量至少为集中质量的四分之一。于是 Dirichlet 原问题的剩余项不超过 $\frac{4}{18a}\sum_i s_i^2/m_i$。流函数的 Neumann 商空间使用常数 $1/9$，并把被钉住点的反力补成 $-\sum s_i$，使右端对常数为零。两常数分别由单位平方的 Dirichlet 与 Neumann Poincaré 常数和 $\pi>3$ 得到。新界与原图路径界取交；小规模精确 Schur 算法保留为对照。

RT1 商空间在真正的 P2 节点基上取精确残差。P2 三角形质量矩阵除以面积后的逆矩阵，最大绝对行和为 57。用 $m'_i=\sum_{K\ni i}|K|$ 可得对偶代数误差平方上界 $(57a/9)\sum_i r_i^2/m'_i$。逐元梯度 Cauchy–Schwarz 给出 $K\preceq 6\operatorname{diag}(K)$，从而得到下界 $\sum_{i\ {\rm free}}r_i^2/(6K_{ii})$。两式在有理数算术中计算。

对精确平衡 P0 数据，间隙平方恰等于原离散误差、原代数误差、对偶空间离散误差和对偶代数误差的平方和。扣除两个代数误差区间得到联合空间下限区间。再用残差见证 $L\le\|u-v\|_a^2$ 扣除原代数误差上界，得到原离散误差下界。对偶空间离散误差的上界为联合空间上界减去原离散下界。当前实现对对偶空间离散误差只建立零下界，无法据此分别识别两个离散误差的准确大小。

## 原空间筛查

第一批性能数据揭示一个负面结果：在几个粗网格上，流函数 Krylov 空间接近收敛后仍无法通过，检查成本反复支出。新增策略先在零边界 P2 空间对当前 P1 残差做一次稀疏试验，得到比固定边中点见证更有针对性的见证方向。独立有理数积分核查该方向，再扣除 P1 代数上界。如果剩余下界严格大于冻结容差平方，则任何当前网格 P1 场都无法达到目标，直接细化是有数学依据的。若下界未越过阈值，程序仍走证书构造。该筛查不能为当前场提供接受决定。

## 复杂度与边界

固定阶次每个单元只贡献常数次条目，装配和稀疏矩阵向量乘法的算术操作数与网格规模同阶。试验方向的精确复核也只扫描稀疏条目，但有理数位复杂度取决于输入和候选精度。P1 块及 P2 见证使用稀疏直接因子，填充量与时间不承诺线性。规模较大时应测试可重复的几何多重网格或 AMG，方向质量仍由精确残差证书兜底。

当前动态打分采用可取得的代数下降下界和量得的局部耗时作为批动作代理。精确原空间下限负责排除不可能达标的当前网格。这里没有关于完备动作集的最优性或竞争比证明。层级基、平衡通量和自适应代数停止已有理论，现阶段研究贡献假设集中在用可核查的原–对偶归因减少无望动作的开销。[平衡通量理论](https://epubs.siam.org/doi/abs/10.1137/130950100) · [层级预条件](https://epubs.siam.org/doi/abs/10.1137/0911069) · [含非精确代数求解的 AFEM](https://doi.org/10.1016/j.camwa.2024.12.013)
