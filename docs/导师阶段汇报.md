# MFEM 科学计算智能体阶段汇报

本篇记录第一阶段。第二阶段的同输入计时、强跳跃扩散与最大网格结果见[第二阶段汇报](导师阶段汇报-第二阶段.md)。

李老师您好，

按照您提出的两个方向，我在 MFEM 求解内核上推进了性能对照和特殊算例扩展。本次在 Ubuntu 24.04 WSL2 中构建了固定版本的 MFEM 4.10。原版 151 项测试与 31 组历史任务均已复现，修改后 160 项测试通过，31 组历史任务的验收、重试和失败决策保持一致。

**性能方面。** 我用相同的网格、阶次、CG + Jacobi 和停止容差比较全装配与部分装配，对正弦和混合边界制造解共做了 30 对正式计时，所有算例均通过独立验证。以正弦 Q2、最细 16,641 个自由度为例，部分装配使刚度算子装配中位数从 17.78 ms 降到 6.14 ms，求解器峰值内存从 18.86 MiB 降到 15.02 MiB。这组试验的成对端到端加速比中位数为 0.993。混合边界算例也观察到部分装配减少装配开销、增加 CG 迭代总耗时。当前尺度下，独立验证用时占端到端成本的大部分。

**工作流优化。** 精度重试现在复用已独立验证的粗网格结果，新增层级继续完整求解和验证。每次尝试保留原始证据文件，归档复核时仍从全部原始数据重新检查。对原重试任务做五对试验，MFEM 和单级验证计算均由 18 次降至 6 次，端到端中位数从 4.253 秒降至 3.466 秒，成对加速比中位数为 1.20。验证器已独立运行，有单独的时间和内存预算。

**特殊算例。** 注册了扩散张量为 diag(1000, 1) 的二维各向异性制造解。使用全装配 Q1 运行四级网格，最细两级的 L²、H¹ 半范数收敛阶分别为 2.000 和 1.000，且独立参考求解能检出错误源项。这个算例验证了张量扩散的注册、求解和独立验证流程。

**下一阶段。** 已建立基于精度约束和实测端到端成本的确定性选型基线。当前试验在 L² 目标 10⁻⁴ 下，两个 Q1 候选均达不到精度，两个 Q2 候选均通过。下一阶段拟扩大 CPU 网格与载荷范围，评估如何降低独立验证成本，并把分层强跳跃扩散的通量和能量检查接入同一证据链。MPI、CUDA 和学习型选型将在得到固定策略与误差基准后分别对照。
