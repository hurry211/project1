# MFEM 科学计算智能体第二阶段汇报

李老师您好，

这一阶段，我围绕您提出的两个方向做了两组实验。性能方面，我用同一份有限元计算结果测量独立验证的成本，再用更大网格比较 MFEM 的两种装配方式。功能方面，我把具有解析通量和能量基准的分层强跳跃扩散接入了原有工作流。

**独立验证在 66,049 个自由度的混合边界算例上快了约两倍。** 我保留了独立装配、SciPy 直接求解和归档校验，只在实际导出坐标证明单元及局部节点完全平移一致时复用计算。五对试验中，验证时间中位数从 4.084 秒降到 1.980 秒，峰值内存从 527.7 MiB 降到 336.6 MiB。五对都通过了逐层数值和验收结论的等价检查。

**在偏心高斯载荷下，部分装配节省了内存，全装配更早完成了整个任务。** 最细网格有 263,169 个自由度。使用相同的 CG + Jacobi、停止容差和三个网格层级时，两种装配最细层均需 1,677 次迭代，独立 L² 误差均约为 5.85×10⁻⁸。部分装配把三级装配时间从 428 毫秒降至 116 毫秒，原生峰值内存从 178.5 MiB 降至 94.8 MiB，但三级 CG 用时从 8.92 秒升至 15.45 秒。三次正式重复的端到端中位数分别为全装配 29.03 秒、部分装配 34.42 秒。

同一个大网格也暴露了验证优化的边界。新旧验证器均接受该归档，但两者报告的最细参考场相对差相差 3.63×10⁻¹²，超出事先设定的 10⁻¹² 跨版本等价阈值。恢复逐单元物理几何计算后，三个层级均复现了旧版的参考场差值。因此，目前可确认的验证加速限于前述混合边界算例。高斯算例的全装配与部分装配对照使用同一版本的验证器，六对正式试验均通过精度等价检查。

**材料对比度 1∶10,000 的分层扩散已能独立验收。** 我选取竖直对齐界面、左右单位势差、上下绝热的单位方形。解析解在每层内都是线性的，适合直接检查节点值、两侧法向通量和积分能量。六级 Q1 网格均通过。最细网格的界面通量跳跃相对值为 1.51×10⁻⁸，低于 10⁻⁵ 的冻结上限。将材料误设为均匀，或把零源项改为单位源项后，MFEM 的 CG 仍正常结束，两组结果都被独立验证拒绝。移动原始归档后再次计算，也复现了这三个结论。

本轮共 170 项测试通过，31 组历史任务的决策及原有故障码全部复现。固定高斯算例的 L² 目标为 10⁻⁶ 时，确定性策略在 66,049 个自由度上选中了全装配。下一步拟先验证分块逐单元参考装配能否兼顾大网格的成本与诊断一致性，再在上述通量、能量门限下比较强跳跃扩散的预条件方法。当前实测范围为串行 CPU，MPI、GPU 与学习型选型仍待实验。
